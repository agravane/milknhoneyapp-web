# MilkNHoney — Landing Page

Static landing page, privacy policy, and terms of service for the
[MilkNHoney](https://github.com/agravane/Milkandhoney) app, served via GitHub
Pages at [milknhoneyapp.com](https://milknhoneyapp.com).

Plain HTML/CSS, no build step. Edit `index.html`, `privacy.html`, or
`terms.html` and push to `main` — Pages redeploys automatically.

`privacy.html` and `terms.html` are kept in sync with the app repo's
`PRIVACY_POLICY.md` / `TERMS_OF_SERVICE.md`; update both places together.
